# CodePath AI — Этапы 1–2 (ядро + насыщенный контент + прогресс)

**Этап 1** — ядро:
- Инициализация Django-проекта, БД SQLite.
- Кастомная модель пользователя с входом по номеру телефона (`users`).
- Профиль пользователя: XP, уровень, серия посещений (стрик), достижения.
- Django Admin для управления контентом.

**Этап 2** — контент и логика прохождения (расширено по запросу):
- **24 урока** по Python и JavaScript (по 3 урока на каждый из 4 уровней сложности для каждого языка).
- Каждый урок: **развёрнутая теория** (3 абзаца, разбор синтаксиса, типичные ошибки), **2 примера кода** с пояснением к каждому, **3 задания** с подсказкой (hint).
- C++ и Java — языки-заглушки («курсы скоро появятся»), контент по ним не входит в Этап 2.
- **Последовательное прохождение уроков**: следующий урок открывается только после завершения предыдущего.
- **Урок завершается только после решения ВСЕХ его заданий** (было — можно было завершить без решения).
- Прогресс-бары на страницах курса, языка и дашборда.
- **Исправлен баг с выходом из аккаунта**: в Django 5+ `LogoutView` принимает только POST-запросы, а не GET-ссылки — кнопка «Выйти» теперь отправляет POST-форму.

## Запуск

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate   # опционально
pip install -r ../requirements.txt
python3 manage.py migrate
python3 manage.py seed_demo        # 4 языка, 24 урока (Python/JS), 48 примеров, 72 задания, 5 достижений
python3 manage.py createsuperuser  # создайте собственную учётную запись администратора
python3 manage.py runserver
```

При публикации проекта не добавляйте локальную базу данных: она уже исключена через `.gitignore`. Создавайте администратора отдельно для своей установки командой `createsuperuser`.

Для production задайте переменные окружения `DJANGO_DEBUG=false`, `DJANGO_SECRET_KEY` (случайный секретный ключ) и `DJANGO_ALLOWED_HOSTS` (список доменов через запятую). Не храните их в репозитории.

Сайт: http://127.0.0.1:8000/
Админка: http://127.0.0.1:8000/admin/

## Структура

```
backend/        — Django-проект (config, users, courses, chat, ai_assistant)
templates/       — HTML-шаблоны (общие для всех приложений)
static/          — CSS/JS/изображения
media/           — загружаемые файлы (аватары)
```

**Архитектурный шаг** — подготовка к полному курсу Python (Beginner → Middle Developer), контент пока не добавлен:
- `Course.LEVEL_CHOICES` расширен с 4 до 7 значений (новые: `elementary`, `upper_intermediate`, `middle`) — старые 4 остались нетронуты, JavaScript их по-прежнему использует.
- У `Lesson` добавлено поле `block_title` — группировка уроков по тематическим блокам («Блок 7. Функции» и т.п.) без отдельной модели `Module` (проще, ничего не ломает; пустое `block_title` = старое плоское отображение, как у JS).
- `templates/courses/course_detail.html` — уроки группируются по `block_title` через `{% regroup %}`.
- `courses/management/commands/seed_demo.py` — Python-контент убран (остался только JavaScript), чтобы не дублировать с новым курсом.
- **Новое:** `courses/management/commands/seed_python_course.py` — пересоздаёт единый курс Python из 5 уровней (Beginner/Elementary/Intermediate/Upper-Intermediate/Middle Developer), удаляя старую демо-заглушку. Пока создаёт только пустые курсы-уровни — блоков с уроками ещё нет.
- **Новое:** `courses/data/python_curriculum/` — пакет с данными курса: один файл `block_XX_<тема>.py` на один тематический блок (без создания сотен строк в одном файле), формат описан в `__init__.py`. Наполняется постепенно, начиная с Beginner.

Прогресс/разблокировка уроков, XP, стрики, аккаунты — без изменений, вся существующая механика переиспользуется как есть.
